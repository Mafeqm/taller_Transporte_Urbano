### Resumen de ejecución:
1. **Levantar PostgreSQL con Docker**:
   ```bash
   docker compose up -d
   ```
2. **Compilar y Correr la Aplicación Spring Boot**:
   ```bash
   cd spring-security-user-role-management
   .\gradlew.bat bootRun
   ```
3. **Acceder a la Documentación Swagger**:
   - URL: `http://localhost:8050/swagger-ui.html`
4. **Acceder al Frontend**:
   - Abrir el archivo `Frontend/index.html` en el navegador.
   - Iniciar sesión con:
     - Usuario: `superadmin`
     - Contraseña: `SuperAdmin123!`
